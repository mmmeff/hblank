# Hblank logo mark

`hblank-mark.svg` is the canonical mark. It uses a solid `#7559E8` fill on a transparent canvas.

- `hblank-mark-gradient.svg` preserves the violet range from the generated concept.
- `hblank-mark-monochrome.svg` inherits `currentColor` when embedded inline.
- `hblank-mark-preview.svg` places the canonical mark on Hblank's `#0B0B10` dark surface.

The 1024-unit master uses a 112-unit stroke. Keep at least 112 units of clear space around the visible mark. Do not add shadows, outlines, or another container.
