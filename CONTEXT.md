# Hblank

Hblank is the context for developing GPUI components in isolation and inspecting their configurable states.

## Language

**Fixture**:
An isolated, discoverable presentation of a component with the information needed to inspect and manipulate it in the harness.
_Avoid_: Example, story

**Fixture file**:
A project source file matched by fixture discovery that may register one or more fixtures.
_Avoid_: Example file

**Harness**:
The application surface that discovers, lists, renders, and controls fixtures.
